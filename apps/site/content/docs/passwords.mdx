---
title: Passwords and recovery
description: Recover a lost owner password without discarding conversations or credentials.
---

## Reset locally

Run the CLI as the account that runs ONE ROUTER, with the same config and data directory. Enter a temporary password of at least 12 characters in the hidden prompt:

```sh verify="cli-reset"
one-router user reset-password
```

Sign in with it and choose a new password. Other signed-in browsers must sign in again.

## Reset in Docker

From the same checkout and with the same Compose environment, run:

```sh verify="docker-reset"
docker compose --env-file docker/.env -f docker/compose.yml exec one-router one-router user reset-password
```

## Reset on a VPS

For the [systemd install](/docs/systemd/), use the `one-router` service account, the same environment file and config path, and the same data directory. An administrator can run a temporary systemd unit with those settings:

```bash verify="systemd-reset"
sudo systemd-run --wait --pty --collect --uid=one-router --gid=one-router --property=EnvironmentFile=/etc/one-router/one-router.env --setenv=ONE_ROUTER_DATA_DIR=/var/lib/one-router --setenv=ONE_ROUTER_CONFIG=/etc/one-router/config.json /usr/local/bin/one-router user reset-password
```

Adjust the executable path if it differs from the unit file. For a Compose install on a VPS, use the Docker instructions instead.

## Reset on Vercel

From a trusted machine, configure the CLI with the production `TURSO_DATABASE_URL`, `TURSO_AUTH_TOKEN`, and `ONE_ROUTER_ENCRYPTION_KEY`, then use the local reset command. Clear those settings from the machine after use. Changing `INITIAL_PASSWORD` in Vercel will not reset an existing owner.

## If you lost the key

Resetting the owner password does not replace the encryption key. Restore the original key or [import a portable archive](/docs/import-export/) into a new instance if you have its passphrase. A database backup alone cannot decrypt encrypted values without its matching key.
